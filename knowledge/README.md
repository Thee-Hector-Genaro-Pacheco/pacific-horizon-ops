# Knowledge (development seed)

Only files placed here (or in `PHRO_KNOWLEDGE_ROOTS`) can be ingested into the PHRO knowledge store. Never put secrets, credentials, tokens, OAuth data, private customer email or personal calendar data in this folder; the ingester refuses common secret file names and credential-like content, but the folder itself must stay clean.

The seed documents in `pacific-horizon-labs/` restate facts from `business.md` and owner-provided policy. Bracketed `[TODO]` values in `business.md` are deliberately recorded as "not yet set" rather than guessed.
